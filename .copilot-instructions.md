# GitHub Copilot Instructions for Minimum Spanning Tree Project

This is a SvelteKit project demonstrating four minimum spanning tree (MST) algorithms: Prim's, Kruskal's, Borůvka's, and Reverse-Delete.

## Project Stack
- **Framework**: SvelteKit with TypeScript
- **Styling**: Pico CSS (@picocss/pico) - A semantic CSS framework
- **Icons**: Lucide Svelte (lucide-svelte) - Beautiful & consistent icons

## UI/Styling Guidelines
- **Always use Pico CSS classes and semantic HTML elements**
- Pico CSS provides automatic styling for semantic HTML (no need for custom CSS classes in most cases)
- Use `<main class="container">` for page layouts
- Use `<article>`, `<section>`, `<header>`, `<footer>` for semantic structure
- Use `<button class="contrast">` for primary actions, `<button class="secondary">` for secondary actions
- Use `<details>` and `<summary>` for collapsible content
- Grid layouts: Use `<div class="grid">` for automatic responsive grids
- Form elements get automatic styling - just use semantic HTML

## Icon Guidelines
- **Always use Lucide Svelte icons** for consistency
- Import icons individually: `import { Play, Settings, Info } from 'lucide-svelte'`
- Use icons with size prop: `<Play size={18} />`
- Common icons for this project:
  - `GitBranch` - for MST/tree representations
  - `Play`, `Pause`, `RotateCcw` - for algorithm controls
  - `Settings`, `Info` - for UI elements
  - `ChevronRight`, `ChevronDown` - for expandable sections

## MST Algorithm Structure
- All algorithms are in `src/lib/mst/` directory
- Each algorithm exports a function that returns `Promise<MSTResult>`
- Use the `Graph`, `Edge`, `MSTResult` types from `./types`
- Algorithms should provide step-by-step explanations in the `steps` array
- Include execution time measurement using `performance.now()`

## Component Patterns
- Use Svelte 5 syntax (`$props()`, `{@render children?.()}`)
- Prefer semantic HTML with Pico CSS over custom styled components
- Use `aria-busy` for loading states
- Use `disabled` prop for buttons during algorithm execution

## Example Code Patterns

### Button with Icon
```svelte
<button class="contrast" on:click={runAlgorithm} disabled={isRunning}>
  <Play size={18} />
  {isRunning ? 'Running...' : 'Run Algorithm'}
</button>
```

### Card Layout
```svelte
<article>
  <header>
    <h3>Algorithm Results</h3>
  </header>
  <p>Content goes here...</p>
</article>
```

### Grid Layout
```svelte
<div class="grid">
  {#each items as item}
    <div>{item.name}</div>
  {/each}
</div>
```

When generating code for this project, always prioritize:
1. Semantic HTML structure
2. Pico CSS utilities and conventions
3. Lucide Svelte icons for visual elements
4. TypeScript type safety
5. Accessible markup (proper ARIA labels, semantic elements)
